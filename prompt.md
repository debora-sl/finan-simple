Crie um sistema de gestão de despesas, com autenticação de usuários.

## Comportamentos esperados

- O usuário pode criar conta e fazer login (nome, e-mail e senha).

- O usuário pode criar despesas.

- O usuário pode criar categorias de despesas.

- O usuário pode, para cada despesa, marcar quais foram pagas.

- O usuário deve conseguir visualizar uma dasboard.
