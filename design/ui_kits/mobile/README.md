# UI Kit — App Mobile

Phone-framed mobile app, mobile-first. `index.html` renders a device frame around `MobileApp.jsx`.

Screens via bottom tab bar: **Início** (balance hero, contas a pagar, gráfico, movimentações), **Extrato**, **Contas**, **Relatórios**, plus a center FAB that opens the "Nova transação" bottom sheet.

Reuses `../dashboard/data.js` and `../icons.js`, and the same design-system primitives as the desktop kit.
