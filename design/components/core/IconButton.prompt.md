Square button holding one icon — toolbars, card action menus, mobile nav.

```jsx
<IconButton label="Mais opções" variant="ghost"><MoreIcon /></IconButton>
<IconButton label="Editar" variant="soft"><EditIcon /></IconButton>
```

Variants: `ghost` (default), `secondary` (bordered), `soft` (tinted blue). Sizes 32/40/44px. `label` is required — it drives both `aria-label` and the tooltip.
